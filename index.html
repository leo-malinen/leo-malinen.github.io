Security Sentinel

Next.js · TypeScript · Tailwind CSS · Ollama

It ingests STIX 2.1 indicators from TAXII 2.1 feeds, normalises them into one searchable store, and surfaces what is trending across sources rather than within any single one.

A local Ollama model runs on a daily schedule and summarises the highest signal activity into a morning intel brief. Every byte of data and every token of inference stays on the machine it belongs to.
